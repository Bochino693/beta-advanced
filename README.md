# Strike Kids — versão ALTA (avançada) · boliche infantil 3D (Bob & Mia)

Versão **ALTA** do Strike Kids: o mesmo jogo da versão do repositório
[`beta`](https://github.com/Bochino693/beta), com o **cenário COMPLETO** como padrão
(chão e céu desenhados pixel a pixel, toda a decoração com contornos e a neblina de
profundidade) — feita para a **TV Box TX9** e TV Boxes mais fortes. A versão LEVE
(TV Box SmartPro, Mali-G31) continua no `beta`.

Jogo de boliche infantil para máquina arcade de **5 sensores**, em **Godot 4.6.1**
(renderizador Compatibility, física Jolt): mascotes fofinhos (Bob, o cachorrinho, e
Mia, a gatinha) com uma **roupinha 3D para cada fase** (piratas no Fundo do Mar,
dinossaurinhos na Selva, astronautas no Espaço, boné de hélice no Parque), **fases
sorteadas**, sol e lua com rostinho, pinos com física de verdade e máquina de pinos
animada.

- Projeto Godot: [`strike-kids/`](strike-kids/) — abra o `project.godot` no Godot 4.6.1 e aperte F5.
- Como testar, gerar o APK, a TV Box TX9 e operar a máquina: [`strike-kids/LEIA-ME.txt`](strike-kids/LEIA-ME.txt)
- Documento do jogo: [`strike-kids/docs/DOCUMENTO_DO_JOGO.md`](strike-kids/docs/DOCUMENTO_DO_JOGO.md)
- O fundo pode ser trocado na própria máquina (menu do operador > "Cenário (fundo)"):
  o padrão desta versão fica em `strike/video/cenario="completo"` no `project.godot`.
